# Barnes–Wall anomaly: proposed proof and exact calculations

**26 November 2026 — Proposed proof; exact finite calculations reproduced internally; external expert review pending.**

This packet proposes a proof of the anomaly-vanishing statement in Keller–Roberts–Roberts, *CFTs with Large Gap from Barnes-Wall Lattice Orbifolds*, [JHEP 04 (2026), 009](https://doi.org/10.1007/JHEP04(2026)009), Conjecture 5.2. The statement concerns the specific extraspecial group action on the rank-128 Barnes–Wall lattice VOA, including the prescribed sign lifts. A compatible generalized quaternion group of order 16 provides the additional restriction needed to eliminate the residual anomaly.

The mathematical text and code were **generated by coordinated AI agents**. Different agents developed the two lift implementations and reviewed the cohomology and extension arguments. These are internal checks, not independent human or external expert validation. The packet is a proposed argument for review, not a formal proof-assistant development or an assertion of priority.

## Attribution and scope

The lattice action, proposed orbifold, twisted-sector weights and low-weight spectrum are due to **Christoph A. Keller, Ashley Winter Roberts and Jeremy Roberts**. Established cohomology and orbifold results supply the theoretical framework. The contribution proposed here is the compatible quaternion lift for their exact action, together with a direct argument covering standardness of every prescribed involution.

If the argument is correct, the full-group orbifold is a strongly rational holomorphic VOA of central charge 128 with Virasoro-primary gap four. The claim is restricted to that algebraic conclusion; unitarity and uniqueness are not established. This is distinct from the extremal central-charge-48 existence question. No claim about lifting the entire Barnes–Wall normalizer is needed.

## Reproduce the finite calculation

Use Python 3.10 or later, without `-O` or `-OO`, from this directory:

```sh
python check_lift.py --output check-report.json
```

This is the primary finite checker. It uses only the Python standard library, arbitrary-precision integers and packed arithmetic over the field with two elements. It constructs the lattice matrices directly from KRR Appendix A, then verifies the lattice isometries, group order 16, cocycle identities, the complete quadratic phase relations, generator phase formulas, and the order-eight cyclic type. It needs no network connection or external data files. Its checks do not certify the separate cohomological and VOA extension arguments.

An optional finite confirmation of the analytic involution lemma is also standard-library-only:

```sh
python check_involutions.py --output involution-report.json
```

It exhausts the 8,256 singular quotient vectors. The 6,176 cases with a nonzero phase formula are checked on a complete basis of the binary fixed space and all pairwise polarizations. The other 2,080 cases have identically zero phase. This computation is supplementary to the analytic proof in Section 3.

For a separate reconstruction from Cartesian Pauli matrices and the subset/Möbius basis, use an environment with NumPy already available:

```sh
python check_lift_alternate.py --output alternate-report.json
```

This alternative uses NumPy integer matrices; the primary checker uses arbitrary-precision arithmetic. The implementations do not import one another and produce the same hashes for the Gram matrix and the two quaternion generators. The stored reports were generated with Python 3.12.14 and NumPy 2.3.5.

All three programs fail closed if assertions are disabled. They overwrite only the named report path when `--output` is supplied. There is no optimization solver, random search, external service, floating-point nullspace, or timeout-based inference in the primary check.

## What the stored reports establish

The primary and alternate reports both verify that the canonical candidate lift needs no character correction and agrees with the prescribed extraspecial action on the common quaternion subgroup. The primary calculation checks every coefficient of each relation by evaluating the quadratic phase differences on 128 basis vectors and 8,128 distinct pairwise basis sums. It reports actual order eight, no fixed vectors, twisted vacuum weight `11/2`, and cyclic type zero.

The reports are reproducibility receipts, not substitutes for running or reading the code. `MANIFEST.json` records the exact file snapshot. Matching hashes establish file identity, not mathematical correctness. The generic exploratory linear-system solver and the exploratory search files are excluded from this packet.
